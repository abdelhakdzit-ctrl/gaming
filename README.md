# gaming — Third-person shooter (Three.js)

## التشغيل
```
python3 -m http.server 8000
```
ثم افتح `http://localhost:8000`. يجب استخدام خادم محلي، فالمتصفح يمنع تحميل الملفات عبر `file://`.

خيارات URL للتطوير:
- `?peaceful`: بدون موجات أعداء.
- `?diff=easy|normal|hard`: مستوى الصعوبة.
- `?orbit=a,r,h,hy`: كاميرا فحص حول الشخصية.

## البنية
| المسار | الدور |
|---|---|
| `src/character/Retarget.js` | نقل حركات FBX من هيكل T-pose إلى Mannequin ذي وضعية A-pose، مع محاذاة الوضعية الأساسية لكل عظمة، واستخراج root motion، واقتطاع دورة مشي واحدة تبدأ بارتكاز القدم اليسرى |
| `src/character/AnimController.js` | blend space للحركة حسب الاتجاه والسرعة، بطور مشترك وسرعة تشغيل تساوي سرعة الأرض مقسومة على سرعة الكليب (بدون انزلاق القدمين)، وطبقة one-shot تطبّق root motion عبر التصادم |
| `src/character/Character.js` | الجزء السفلي من الجسم من الحركات؛ والجزء العلوي من وضعيات القبضة المخبوزة؛ ومحاذاة السبطانة مع نقطة التصويب؛ وارتداد بنوابض؛ وIK لليدين على السلاح |
| `src/weapons/GripLibrary.js` + `src/data/grips.json` + `assets/weapons/*.glb` | وضعيات اليدين والأصابع وموضع السلاح، وتسلسلات التلقيم والترباس، مخبوزة من `legacy-viewer` |
| `src/data/clips.js` | سجل الحركات (`range` لاقتطاع one-shot، و`reverse` لعكس الكليب) |
| `src/data/weapons.js` | إحصاءات الأسلحة |

## root motion
- **كليبات الحلقة (مشي/جري):** تُحذف الإزاحة الأفقية للحوض وتتحول إلى `userData.vel`، أي سرعة الكليب الطبيعية. سرعة الشخصية القصوى في كل اتجاه مأخوذة من الكليب نفسه، فالرجوع للخلف أبطأ من التقدم.
- **one-shot (قفز، تدحرج، تجاوز عائق، دوران):** يبقى الارتفاع داخل الحركة نفسها، أما الإزاحة الأفقية والدوران فيُعادان عبر `onMove(dx, dz, dyaw)` ويُطبَّقان مع التصادم.

## القبضة (الكف والأصابع)
وضعيات اليدين غير مكتوبة يدوياً في الكود، بل تُخبز من محلّل القبضة في `legacy-viewer`. يشمل ذلك ملاءمة السلاح لليد، وإغلاق الأصابع على مقابض التصادم، وموضع اليد الداعمة، ووضعية إصبع الزناد، وحركات التلقيم.

لإعادة الخبز بعد تعديل `legacy-viewer`:
```
python3 dev/bake/server.py 8130
# افتح http://127.0.0.1:8130/dev/bake/bake.html (أو شغّله بمتصفح headless)
```

فحص جودة نقل الحركات: افتح `dev/retarget-check.html`. يعرض الصفحة سرعة كل كليب، ومقدار انزلاق القدم، وخطأ اتجاه العظام.

## إضافة محتوى
- **حركة جديدة:** ملف FBX في `assets/animations/`، ثم سطر في `CLIPS`، ثم استدعاء `character.anim.playOnce('name')`.
- **سلاح جديد:** أضف النموذج والقبضة في `legacy-viewer`، ثم أعد الخبز، ثم أضف مدخلاً في `WEAPONS` يحمل `model` المطابق.
